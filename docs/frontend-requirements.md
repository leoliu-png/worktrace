# WorkTrace 前端需求

## 结构

页面复用 Stitch 导出的 HTML、Tailwind 令牌、字体和布局；不在运行时调用 Stitch。用户页面对应本地导出 HTML，管理员页面使用同一品牌标识、侧栏宽度、主色、表格和卡片层级。

## 可见性与路由

- 会话角色决定导航集合；成员导航仅含概览、工作日志、新建日志、API Keys、我的日志。
- 管理员导航追加成员管理、权限控制、日志管理、安全审计。
- 成员直接打开 `/console/admin/*` 时重定向至 `/console?access=denied`。
- 桌面保留固定侧栏；小屏幕遵循 Stitch 设计系统的折叠导航和单列内容规则。

## 状态

使用加载、空数据、筛选无结果、无权限和错误提示；不通过隐藏菜单替代路由授权。

## 当前组件边界

- `ConsoleShell` 负责 Stitch 风格的顶部栏、左侧导航与响应式外壳。
- `ConsolePageFrame` 从 Auth.js 会话读取角色；未登录返回首页，成员打开管理员路径返回控制台。
- `LogList`、筛选面板、结构化日志表单与 API Key 列表均为可复用组件，不把领域逻辑放进页面。
- 所有屏幕以本地 `stitch-worktrace/html` 为设计来源；运行时不依赖 Stitch 服务。

## 无障碍与国际化

- 所有输入都有可访问标签，按钮可键盘聚焦，状态文本不能只靠颜色表达。
- 系统 UI 文案通过统一词典提供中英版本；日志正文、标题不自动翻译。
